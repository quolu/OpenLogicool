# マビモバの回復判定用画像

製品のWGC保存画像から、利用者が許可した食事1個の使用前後のHUDを切り出した。`before.png`と`after.png`は元の2203×1319座標を保ち、HUD以外を黒くしたfixture。小画像3枚はHUD表示・食事使用前・食事効果中の照合に使う。Computer Useの画像ペイロードは使用していない。

`profile.json`はこの画面サイズと登録状態での実測値。F1は登録スロット1の通常回復ポーション、Bは画面に出る食事。食事の20分と薬の10秒はゲーム内説明で確認した。包帯は自動使用しない。基本フードの選択は変更しない。

全快の使用前後は実画像、HP50％・25％は枠を維持して充填だけを減らした試験画像で検証する。低HP・戦闘・効果切れ直前・別サイズでの実機成立をfixture試験だけで主張しない。使用前後の比較は[調査記録](../../../rag/openlogicool/mabinogi-recovery-food-2026-10-08.md)を参照する。
