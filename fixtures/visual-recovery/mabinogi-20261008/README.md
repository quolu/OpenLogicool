# マビモバの回復判定用画像

`dungeon-clear.png`はキア1Fエリア1のSランク結果画面を製品WGCで取得した画像。「協力ボーナス」と「行動不能にならずにクリアしました」を含むが、選択や敗北として停止せず、画面の進行指示へSpaceを送る負例として使う。死亡判定は「行動不能」と復活操作の同時表示を条件とする。

製品のWGC保存画像から、利用者が許可した食事1個の使用前後のHUDを切り出した。`before.png`と`after.png`は元の2203×1319座標を保ち、HUD以外を黒くしたfixture。小画像3枚はHUD表示・食事使用前・食事効果中の照合に使う。Computer Useの画像ペイロードは使用していない。

`profile.json`はこの画面サイズと登録状態での実測値。F1は登録スロット1のポーションでHP70％以下から使用する。登録品の変更と戦闘結果は[実測記録](../../../evidence/mabinogi-key-assist-20261008/recovery-advanced-live.md)を参照する。Bは画面に出る食事。食事の20分と薬の10秒はゲーム内説明で確認した。白20％以上で包帯F2を使用し、待ち時間は5秒。基本フードの選択は変更しない。

全快の使用前後は実画像、HP50％・25％は枠を維持して充填だけを減らした試験画像で検証する。低HP・戦闘・効果切れ直前・別サイズでの実機成立をfixture試験だけで主張しない。使用前後の比較は[調査記録](../../../rag/openlogicool/mabinogi-recovery-food-2026-10-08.md)を参照する。

`combat.png`は再挑戦で食事アイコンが他の効果に押されて右へ移動した実画像。食事は効果の行全体から探す。枠の色は実測の固定RGB値に合わせ、下辺の右端が下の行で丸く内側へ戻る形も照合する。近似色の背景を枠へ連結して全長を過大に読む欠陥は、実画像と枠に隣接させた背景の試験で修正確認する。

`food-timer.png`は商人会話終了後、食事アイコンの上半分へ残り時間の暗い表示が重なった実画像。食事効果の照合だけRGBの最大値で明るさを正規化し、時間表示による暗さを吸収する。停止画像・HUD・使用前ボタンの照合は従来の色を使う。別の戦闘効果と重なった画像の判別は未成立であり、この修正だけで戦闘全体の成立を主張しない。

`damaged.png`は食事未使用の再戦で、白い被弾表示がHP下辺を分断した実画像。左端と右端の丸みを独立に測り、白を残量へ数えない。食事効果の照合基準は、正例とこの負例を分離する差分8以下。食事Bの小領域は固定倍率で精密に照合し、粗い探索で異なる倍率が勝つことによる取りこぼしを避ける。

`window-small.png`（1810×1083）、`window-narrow.png`（1506×1084）、`window-short.png`（1508×846）はNanoで実際に窓を縮小して撮影したHUD。いずれも食事使用前。描画領域は窓枠の左右各1px・上31px・下1pxを除く。HUDは1920:1080の比率に収まる倍率で変化した。参照画像も同じ倍率へ縮小することで、小さい文字の平滑化に合わせる。全画面のAI解析は使わない。

`progress.json`は確認済み画面の進行規則。`dialogue-screen.png`・`dialogue-day.png`・`dialogue-tail.png`は会話の末尾と昼夜の背景差、`dialogue-wide.png`は形が異なる吹き出しの実画像。スキップ表示がある会話は文字の組合せ、末尾は白い吹き出しの形と文字を照合する。`class-level.png`はSpaceで閉じるダンサーのレベル表示、`bonus-three.png`は自動で選ばず全3択を通知するボーナス画面。`stop.png`は利用者から渡された停止表示の画像。HUDと停止表示の倍率・窓内位置は現在の描画領域へ合わせる。画像は製品撮影と利用者提供の原本を保持する。

`dialogue-cue.jpg`は利用者提供の回転する会話待ちの印。`dialogue-ocr-broken.png`はOCRが崩れて停止した製品撮影原本。`ImageRotates`は回転形状の照合を選び、固有名や台詞を条件にしない。回転・倍率・位置変更、印を消した会話、HUD・選択画面の負例を試験する。実画面では異なる向き3種類を含む5枚すべてで検出した。詳細は[実測記録](../../../evidence/mabinogi-key-assist-20261008/progress-script-live.md)。

`compass-space.png`は利用者提供の右下コンパス原本。`compass-screen.png`はBotが演出待ちと判定した実画面。原本の緑の外周4領域とSpaceラベルを`ImageStableRegions`で指定し、針・外周の淡い揺れ・背景を比較から除く。画像の基準描画幅は保存実画面に合わせる。縮小時は参照も描き直し、各領域それぞれが一致した場合だけ検出する。`Immediate`は文字認識と待ち時間を省く画像キー規則。針の6方向・倍率・位置、通常HUD・停止表示・ラベル欠落、同じ表示への再送抑止を`CompassSpaceTests`で確認する。

`loot-reveal.png`はマス1Fエリア2の報酬表示で、Spaceを送らず待機していた製品撮影原本。実ログではSpace後に自動着用・退出へ進行した。`loot-continue`は見出しの10秒表示を条件にSpaceを1回送り、既存の自動着用・退出規則へつなぐ。`MinimumVisibleMs`は同じ条件の表示待ち時間。キャラや報酬の描画変化を表示条件の変化と扱わない。
