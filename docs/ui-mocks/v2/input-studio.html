いまの画面から変わること

  • 図を大きくする。キーの上の操作名が読める大きさになります（今は約6pxの文字）。
  • 割り当てたキーが操作の色で光る。操作を選ぶと、そのキーだけが強く光り、ほかは暗くなります。
  • 絵のボタンが押せる手応えを持つ。押すと沈み、輪が広がります。実機のボタンを押した時も同じ表示になります。
  • 図の M1〜M3 で配置を切り替えられる。上の切替と同じ動きです。
  • 操作の一覧に送るキーをキーキャップで出す。「Key:W を送る」という内部の書き方は出しません。
  • 操作の色を8色にする。今は4色の使い回しで、別の操作が同じ色になっています。
  • G600 上面の小さいボタンは対応表で読む。表の行と絵の位置が連動して光ります。
  • 保存の状態を1か所で示す。未保存があると保存ボタンがゆっくり光ります。
  • タイトルバーを暗色にする。白い枠が浮かなくなります。

変えないこと

  • 画面の3列構成（操作・図・割当）と下の動作チェック。
  • 機能と文言。G13 の LCD 表示、G600 本体への書き込み、出力方式、診断の入口も残します（この見本では省略）。
  • デバイスの色（G13 は水色、G600 は橙）。
  • 線画の絵。今の絵をそのまま使います。

この見本の決まり

  • アプリ名・操作・数値は見本です。クオ君の設定ではありません。
  • 文字は Windows に入っている BIZ UDPゴシックを使います。英数字の見出しとキーの文字だけ、専用の書体を同梱します。
  • スマホでは全体を縮小して表示します。触って試すのは PC が向いています。
