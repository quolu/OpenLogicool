## 挙動の観測

- **状態型 report**: 長押し2.1秒間 bit 保持を確認。chord（G1+G2）は同一 report 内の独立 bit。
- **legacy 二重配送を実測**: 現行 LGS profile 下で、G キー8個の押下に同期して LGS 仮想キーボード（PID C232）が VKey A,S,D,Z,X,C,V,B を配送した。vendor report と仮想 KB の重複分類（計画の記録項目）の実例。
- **G0-Device-RO 受入①**: G13 主要入力経路（G1〜G22・M列・LCD列・スティック XY＋押込み）は user-mode Raw Input で成立。**確認済み**。
