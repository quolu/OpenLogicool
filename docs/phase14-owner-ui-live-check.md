## 再開位置

記録方式と往復採用の修理案への裁定を受け、承認範囲でfocused再現・修理・開発版更新へ進む。各画面で60秒待つ手順を受入の代わりにしない。今回の原本は保持し、往復成功の証拠には使わない。

更新後は本体`nikke`を対象に、通常の操作間隔で可逆メニューの実UI確認を行う。課金・消費・募集・戦闘は今回の確認対象に含めない。

記録済みデモの操作一覧と保存内容を照合した後、同じGame Operatorから候補マクロ作成と再生へ進む。ゲーム内の成功は実画面で確認し、API成功や保存成功から推定しない。課金・消費・募集・戦闘は今回の確認対象に含めない。
