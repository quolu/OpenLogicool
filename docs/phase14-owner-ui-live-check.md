## 再開位置

修正版で新しい記録を始める。マクロ画面の「対象ゲーム（保存）」は本体`nikke`を選び、記録画面の目的へ「アークを開いてロビーへ戻る」を入力して「記録開始」を押す。ランチャー`nikke_launcher`を記録対象には選ばない。修理前の原本は成立証拠に使わない。

「記録中」または「対象アプリから外れたため一時停止中」の表示を確認したら、NIKKEを前面にして可逆メニュー操作の確認へ進む。設定画面が前面にある間の一時停止は正規の動作。開始エラーなら表示全文を受け取り、原因を確認してから修理する。

記録済みデモの操作一覧と保存内容を照合した後、同じGame Operatorから候補マクロ作成と再生へ進む。ゲーム内の成功は実画面で確認し、API成功や保存成功から推定しない。課金・消費・募集・戦闘は今回の確認対象に含めない。
