# G13 バックライト色の標準 HID 書き込み gate

- 実施日: 2026-10-10
- 対象: Logicool G13（VID 046D / PID C21C・firmware release 0203）、Windows 11 build 26200、LGS・G HUB 非稼働
- 判定: **確認済み**（4条件すべて成立）
- 道具: `OpenLogicool.Probe g13-backlight-smoke`
- 命令の根拠: [rag/openlogicool/g13-backlight-color-2026-10-10.md](../../rag/openlogicool/g13-backlight-color-2026-10-10.md)

## 安全の取り決め（実行前にオーナーへ提示・GO 取得）

- 送るのは feature report 7（色）だけ。driver・firmware・保存済みの設定には触れない。
- 戻し方は、色を1回書き直すか G13 の抜き挿し。
- 段階ごとに進め、前の段が通った時だけ次へ進む。色を書くたびに本体へ保存する作りと分かったら、連続の書き込みは行わない。

## 結果

| 条件 | 結果 | 根拠 |
| --- | --- | --- |
| Windows 標準 HID で色を書ける | 確認済み | `HidD_SetFeature`（report ID 7・`07 FF 00 00 00`）が成功。オーナーが目視で赤を確認。読み戻しも `07 FF 00 00`（`probe-output/g13-backlight-smoke-20261010-160531-370.json`） |
| 色は本体に保存されない | 確認済み | オーナーが USB を抜き挿しした後、読み出しが元の `5A FF 6E` へ戻った（`…-160953-837.json`）。書く前の読み出しも `5A FF 6E`（`…-160520-307.json`） |
| 連続で書ける | 確認済み | 毎秒 30 回 × 40 秒 = 1200 回、失敗 0、1回あたり中央値 0.31 ms・最大 1.04 ms（`…-161100-878.json`） |
| 書いている間に入力が欠けない | 確認済み | 常駐 Host 稼働中に毎秒 30 回 × 30 秒 = 900 回を書き、その間のオーナーの G1 押下が道具側で down 11・up 11、Host 側の処理件数も +22 で一致。取りこぼし 0・resident fault なし（`…-162653-013.json`） |

## 分かったこと

- 読み出し（`HidD_GetFeature`・report ID 7）は `[先頭 byte, 赤, 緑, 青, …]` を返す。先頭 byte は最後に書かれた値がそのまま残る（電源投入直後は `00`、こちらが書いた後は `07`）。色は 2〜4 byte 目。
- 公開実装 libg13 は先頭 byte を `05` で送るが、Windows の `HidD_SetFeature` が要求する `07`（report ID）でも firmware は色として受け付ける。
- 電源投入直後の色は `5A FF 6E`（緑寄り）。
- M ランプ（report ID 5）は読み出しだけ行い、書いていない。

## 実施中の逸脱と対処

- 「入力が欠けないか」の測定は、合図がオーナーへ伝わらず 2 回、開始前に時間切れになった（`…-161339-127.json`・`…-162029-113.json`。どちらも色の連続書き込みは始まっていない）。3 回目は常駐 Host を動かしたまま行い、Host 自身の入力件数と突き合わせた。
- 実験のため 16:04〜16:22 の間、アプリ（Bot）を `app close` で止め、`bot start` で戻した。停止時に G600 の残置は復元済み（F3 出荷割当）。
